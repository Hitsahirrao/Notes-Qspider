Attribute-

  • Attributes are the properties.
  • It is use to provide addition info. about the tag
  • There are 2 types of attributes.

1) Global attributes-

  • This attributes use with any tag.
  • ex- id, class, title, style, etc.

2) Element specific attributes:-

  • This attribute can be use with specific tag only.
  • ex- href (<a>), target, src (img, video audio)

Attributes must be written in opening tag.

Semantic tags:-

  • This are self explanatory tag.
  • This tag name tells the use of the tag.
  • We use semantic tags to increase readability of code and semantic tags helps in SEO (Search engine optimization).
  • Ex- nav, header, footer, img, form, button etc.

Difference between block & inline element.

Block

  1. Block level element it always start from new line.
  2. It occupies full width (100%) of the container.
  3. It accepts width & height
  4. ex:- div, p, h1 to h6 nav etc.

inline.

  1. Inline element it start with same line.
  2. It occupies the width of context.only
  3. It does not accept width & height.
  4. span, img, iframe, etc.
